# CRM / Sales Management Portal

A full-stack CRM application for managing **leads, sales opportunities, customers, and follow-ups** for a B2B company.

## Features

* Lead creation, assignment, search & filtering
* Lead status and lead conversion
* Sales pipeline: New → Contacted → Qualified → Proposal → Negotiation → Won/Lost
* Customer and contact management
* Calls, meetings, notes & follow-ups
* Sales dashboard with pipeline value and conversion rate
* Role-based access for Admin/Sales Manager and Sales Representative

## Tech Stack

* **Frontend:** React.js, JavaScript, CSS
* **Backend:** Java, Spring Boot, REST API
* **Database:** MySQL
* **Tools:** Git, GitHub, Postman
